# PL Standings ETL

This project is a small ETL practice pipeline focused on pulling football standings data from an external API and storing it in PostgreSQL. The goal is to build a clean workflow for extracting data, transforming it into a usable format, and loading it into a database for further analysis.

## Project Overview

The workflow follows the standard ETL process:

- Extract: pull live data from a public API
- Transform: clean, normalize, and prepare the data for storage
- Load: insert the processed data into PostgreSQL

This is mainly a hands-on project to improve my Python, data processing, and database workflow skills while building a practical data pipeline.


## Libraries + Installation

- pandas
- requests
- python-dotenv
- psycopg

Install dependencies with:

```bash
pip install -r requirements.txt
```
